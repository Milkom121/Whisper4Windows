# Whisper4Windows — Istruzioni per gli agenti

Il progetto adotta il Metodo Villa ufficiale. Prima di lavorare leggere, in ordine:

1. `CLAUDE.md` — regole specifiche del progetto.
2. `.claude/metodo-villa/00-CLAUDE-OPERATIVO.md` — regole operative del Metodo.
3. `PROJECT_CONFIG.md` — architettura, comandi e limiti verificati.
4. `ROADMAP.md` — blocco corrente e gate di uscita.
5. `docs/diario/handoff.md` — stato e prossimo passo.

Le istruzioni valgono anche per Codex: non presumere che import e skill di Claude
Code vengano caricati automaticamente. Aprire le skill pertinenti in
`.claude/skills/` prima di applicarle. Consultare i capitoli necessari al lavoro,
senza ricaricare istruzioni gia' presenti nel contesto.

Comunicare in italiano, in modo breve, concreto e colloquiale. Distinguere
funzioni disponibili, risultati verificati e proposte; fare una domanda alla volta
quando serve una decisione di Mario. Le istruzioni esplicite dell'utente prevalgono.

Configurazione dell'app e commenti del codice seguono `CLAUDE.md`.
Le vecchie istruzioni sono in `docs/storico/AGENTS-pre-metodo.md`:
sono documenti storici, non un secondo protocollo attivo.
